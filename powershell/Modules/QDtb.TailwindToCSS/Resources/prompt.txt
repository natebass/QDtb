🧮 Default Padding Scale
Tailwind’s default spacing scale includes these values:

p-0 through p-96 (in increments like 0.5, 1, 1.5, 2, 2.5, ..., 96)

p-px for 1px padding

Each number corresponds to a rem value based on the default scale:

p-1 = 0.25rem (4px)

p-2 = 0.5rem (8px)

...

p-96 = 24rem (384px)

You can use these with any directional variant:

pt-, pr-, pb-, pl- (top, right, bottom, left)

px-, py- (horizontal, vertical)

ps-, pe- (logical start/end)

🛠️ Custom Values
Tailwind also supports arbitrary values:

p-[5px] → exactly 5px

p-[2.75rem] → exactly 2.75rem

p-[var(--my-padding)] → CSS variable

p-(--my-padding) → shorthand for p-[var(--my-padding)]

also make sure to include all values from sm to <number>xl
